Frontend: Built with ReactJS for a modern, responsive user interface.
	Backend: Powered by FastAPI for high-performance APIs.
	Data Streaming: Utilizes Kafka for event streaming with core modules in C and Go for efficiency
	Caching: Redis for in-memory caching and fast data retrieval. 
	Databases: PostgreSQL for structured data storage and OpenSearch for indexing and fast search capabilities.
	Provisioning: Utilizes Ansible to push configuration on agents. 
	Collaboration: Source code hosted on GitHub for open collaboration.
	Hosting: Planning to host in AWS in the short future.
	Real-Time Monitoring: Combines logs, traps, flows, and telemetry for complete network visibility.
